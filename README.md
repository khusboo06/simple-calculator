🧮 Basic Calculator

📌 Project Overview

This is a stylish and responsive basic calculator web application built using HTML, CSS, and JavaScript. It performs fundamental arithmetic operations and offers a smooth user experience with a modern UI design.


❓ Problem Statement & Solution

🔴 Problem:  
Manual calculations and unresponsive online calculators often lack good UI/UX and intuitive control flow.

✅ Solution:  
This calculator provides:

- A clean and responsive interface.  
- Support for basic arithmetic operations (+, −, ×, ÷, %).  
- Functional clear (C), backspace (⌫), and result (=) operations.  
- Evaluation of real-time inputs with error handling.


🛠 Tech Stack

Component | Technology  
--------- | -----------  
Frontend | HTML, CSS (Custom), JavaScript  
Styling | Custom CSS with hover effects, grid layout  
Icons | Unicode characters for clean interface


⚙️ Functionality Breakdown

1️⃣ Arithmetic Operations  
Perform addition, subtraction, multiplication, division, and percentage calculations.

2️⃣ Input Management  
Includes Clear (C), Backspace (⌫), and supports decimal input.

3️⃣ Responsive UI  
Mobile-friendly design with interactive buttons and glowing shadows for a modern touch.


📥 Installation & Setup Guide

🛠 Prerequisites:  
Any modern web browser (Chrome, Firefox, Edge, etc.)

📌 Steps to Run Locally:  
1. Clone or download the repository  
2. Open the index.html file in your browser  
3. That’s it! You’re ready to calculate
